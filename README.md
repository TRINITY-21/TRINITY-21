## Pinned Work

### AI / LLM
- 💳 **[mcp-server-paystack](https://github.com/TRINITY-21/mcp-server-paystack)** — Model Context Protocol server exposing Paystack's payment API as tools for AI agents. [`pip install mcp-server-paystack`](https://pypi.org/project/mcp-server-paystack/)
- 📐 **[dotruler](https://github.com/TRINITY-21/dotruler)** — One config, every AI coding tool, always in sync. Generates `CLAUDE.md`, `.cursorrules`, `copilot-instructions.md` from a single source. [`pip install dotruler`](https://pypi.org/project/dotruler/)
- 📰 **[tldr](https://github.com/TRINITY-21/tldr)** — AI-powered URL/article summarizer for the terminal, built on Groq + Llama
- 🌐 **[tldr-web](https://github.com/TRINITY-21/tldr-web)** — Web companion with streaming summaries, multi-language translation, and Q&A mode

### Tools & Infrastructure
- 🐺 **[huntd](https://github.com/TRINITY-21/huntd)** + **[huntd-vscode](https://github.com/TRINITY-21/huntd-vscode)** — Local git analytics dashboard. Streaks, heatmaps, language trends, repo health. CLI + VS Code extension.
- 📡 **[briefkit](https://github.com/TRINITY-21/briefkit)** — Production-shaped REST API: weather, crypto, and news with API keys, rate limiting, TTL caching, and Swagger docs
- ⚡ **[zap](https://github.com/TRINITY-21/zap)** — Python's `subprocess`, but actually nice. Pipe chaining, async, zero deps. [`pip install zap-sh`](https://pypi.org/project/zap-sh/)
- 🧹 **[sweep-cli](https://github.com/TRINITY-21/sweep-cli)** — Find and clean dev artifacts (`node_modules`, `.venv`, `target/`) across all projects, with an interactive TUI
- 🎬 **[videodrop](https://github.com/TRINITY-21/videodrop)** — 34 free browser-based video tools (FFmpeg.wasm). No uploads, no servers.

### Side Apps
- 🤖 **[pingbot](https://github.com/TRINITY-21/pingbot)** — Telegram bot for daily briefings + a trivia game
- ⚡ **[pulse](https://github.com/TRINITY-21/pulse)** — Live TUI dashboard (weather, crypto, news, GitHub) in Go
- 🔍 **[snoop](https://github.com/TRINITY-21/snoop)** — CLI price tracker with web scraping and Telegram alerts
